# Termómetro Partido?

Página estática (`index.html`) com:

1. **Avaliação crítica** da tese da «inflação real» apresentada num episódio do podcast Bitcoin Talks: a tabela do episódio refeita, cada alegação verificada contra INE, Eurostat, BCE e Banco de Portugal, e uma calculadora de sensibilidade.
2. **Proposta de radar de shrinkflation/skimpflation** para Portugal: fontes de dados, regras de deteção, modelo de dados e plano de protótipo.

Abrir `index.html` num browser. Sem dependências além de Google Fonts.
